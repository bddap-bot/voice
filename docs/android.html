Live Voice for Android

Download the app (version 7)

Android 9 or newer. The app runs the Live page and keeps it hearing while hidden.

Install

  1. Tap the download button, then open the downloaded file.
  2. If Android asks, open Settings, turn on Allow from this source, and go back.
  3. Tap Install, then Open.
  4. Allow microphone access while using the app, and allow notifications.

You can turn off “Allow from this source” afterwards.

Updating

Version 7 installs over versions 2 to 6 and keeps the connection token. Uninstall version 1 first. Browser storage and the browser voiceprint do not carry over; use Learn my voice again for voice filtering.

Stopping

Swiping Live Voice away from Recents, or Close in its notification, ends listening.
